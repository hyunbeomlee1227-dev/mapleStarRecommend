# 직업별 계산과 보스 목표 기준

Status: ready-for-human
Type: research
Depends on: 01

## 완료 기준

- 솔로 조건에서 전 직업의 장비 변경 효과 계산식과 검증 사례 및 지원 현황을 정리한다.
- 최종 데미지 증가율의 기준, 버프, 보스 난이도와 특수 효과 처리 방식을 정의한다.
- 인기 장비 기반 관리자 추천 목록과 전체 성능 충족 판정을 분리한다. 목록 밖 장비도 인정한다.
- 보스별 관리자 추정 기준의 근거와 버전을 관리한다. 근거 없는 충족 임계값을 만들지 않는다.
- 최상위 보스 기본값과 후보 강화 목표 선정 방식을 정의한다.
- 검증 기준값으로 결과를 재현하고 필수 데이터 부족 시 판정 불가를 반환한다.

## 조사에서 이어받은 항목

- [API 조사](../api-research.md)의 공식 연무장 결과와 입장 시 캐릭터 정보 API를 전후 검증 자료로 검토한다. 실응답 접근과 동일 조건은 별도 확인한다.
- 현재 세트의 `set_option_full`만으로 미착용 장비 전체의 세트 소속을 안다고 가정하지 않는다. 구매 후보의 세트 소속과 럭키 아이템 규칙을 별도 검증한다.
- 잠재 문구와 능력치 문자열을 파싱하며 미지원 문구는 조용히 0으로 처리하지 않는다.
- 전체 능력치에 장비 옵션을 중복 합산하지 않도록 전후 계산의 기준을 명시한다.

## Comments

### 2026-09-10 구현 진행

- 넥슨 공식 보스 콘텐츠 목록을 기준으로 초기 솔로 목표 18개와 최상위 기본 목표를 버전 관리 데이터로 추가했다.
- 목표 선택 API와 UI, 브라우저 저장소 기반 선택 유지, 선택한 보스별 판정 상태 API를 구현했다.
- NEXON Open API의 `final_stat`에서 스탯 공격력, 데미지, 보스 데미지, 최종 데미지, 방어율 무시, 크리티컬 관련 수치, 전투력, 포스를 검증하여 전투 스냅샷으로 변환한다.
- 공식 설명만으로 전 직업의 장비 변경 전후 최종 데미지와 솔로 클리어 임계값을 재현할 수 없으므로 결과를 만들지 않는다. 현재 모든 목표는 `pending`이며 UI에는 `관리자 기준 검증 중`으로 표시한다.
- 전 직업 계산식 검증 사례와 보스별 관리자 기준 데이터셋은 사람의 검증이 필요하므로 티켓 상태를 `ready-for-human`으로 변경했다.
- 조사 근거와 미해결 항목은 `../combat-model-research.md`에 기록했다.
- 목표 선택 UI를 보스와 난이도의 종속 선택으로 분리했다. 보스 변경 시 같은 난이도가 있으면 유지하고, 없으면 해당 보스의 가장 높은 등록 난이도를 선택한다.
