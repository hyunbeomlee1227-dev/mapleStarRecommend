# 공식 데이터와 강화 규칙 조사

Status: ready-for-agent
Type: research
Progress: source-survey-complete; numeric-validation-pending
Depends on: none

## 완료 기준

- 공식 API의 캐릭터, 장비, 두 잠재능력, 추가옵션, 세트와 능력치 필드를 요구사항에 매핑한다. 없는 정보와 추가 입력을 명시한다.
- 인증, 갱신 시점, 호출 제한과 월드 범위를 확인한다. 실제 응답 미검증은 문서 확인과 구분한다.
- 강화 확률, 비용, 이벤트, 옵션 보존과 복구 조건의 공식 출처를 확보한다. 개인 확률 이력을 게임 전체 확률표로 오인하지 않는다.
- 경매장 API 제공 여부와 공개 서비스 출처 표기 및 보관 조건을 확인한다.
- 출처 링크, 확인일과 미해결 항목을 조사 문서에 기록한다. API 키는 기록하지 않는다.

## 시작 자료

- https://openapi.nexon.com/game/maplestory/
- https://openapi.nexon.com/ko/guide/request-api/

대화에서 공식 목록에 경매장 조회가 확인되지 않았다. 최신 문서를 재확인하되, 첫 버전은 사용자 제공 이미지와 가격으로 비교한다.
