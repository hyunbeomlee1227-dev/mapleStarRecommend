## 완료 기준

- 공식 API의 캐릭터, 장비, 두 잠재능력, 추가옵션, 세트와 능력치 필드를 요구사항에 매핑한다. 없는 정보와 추가 입력을 명시한다.
- 인증, 갱신 시점, 호출 제한과 월드 범위를 확인한다. 실제 응답 미검증은 문서 확인과 구분한다.
- 강화 확률, 비용, 이벤트, 옵션 보존과 복구 조건의 공식 출처를 확보한다. 개인 확률 이력을 게임 전체 확률표로 오인하지 않는다.
- 경매장 API 제공 여부와 공개 서비스 출처 표기 및 보관 조건을 확인한다.
- 출처 링크, 확인일과 미해결 항목을 조사 문서에 기록한다. API 키는 기록하지 않는다.

## 2026-09-12 공식 무릉 표본 검증

- NEXON 공식 무릉도장 랭킹과 캐릭터 장비 API를 인증된 실제 응답으로 연결했다.
- 2026-09-10 상위 20명 장비를 모두 조회했으며 캐릭터 이름과 OCID는 저장하지 않고 직업·슬롯·아이템 사용 수만 집계했다.
- 빈 월드·직업 선택 파라미터는 NEXON에서 오류가 되므로 URL에서 제외하도록 공통 클라이언트를 보정했다.
- 표본에는 이벤트 장비와 교환용 아이템이 섞일 수 있어 집계 결과를 자동 구매 추천으로 사용하지 않는다.

## 2026-09-12 직업별 종합 랭킹 표본 검증

- 공식 무릉 통달 랭킹은 일부 직업이 3명 미만이고 일반 구간은 0명인 사례가 있어 균등 표본에 사용할 수 없음을 실제 응답으로 확인했다.
- NEXON 공식 종합 랭킹의 직업·전직 필터는 히어로와 패스파인더 모두 페이지당 200명을 반환하는 것을 확인했다.
- 공식 필터에 등록된 최종 직업 48개에서 각 3명씩 총 144명의 장비를 2026-09-11 기준으로 수집했으며, 캐릭터 이름과 OCID는 저장하지 않았다.
- 한 직업이라도 3명을 확보하지 못하면 기존 파일을 교체하지 않는다. 호출량과 최종 스냅샷은 프로세스 간 잠금 및 원자 저장을 사용한다.
- 이 표본은 직업별 장비 사용 참고로만 제공하며 보스전 성능, 구매 가격 또는 강화 효율 순위의 근거로 사용하지 않는다.
