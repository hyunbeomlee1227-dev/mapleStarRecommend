## 완료 기준

- 조사에 맞춰 기술 스택과 실행 방법을 정한다.
- 회원가입 없이 캐릭터 이름으로 조회하고 장비와 데이터 기준 시점을 표시한다.
- 인증 정보를 클라이언트나 로그에 노출하지 않는다.
- 없는 캐릭터, 호출 제한과 데이터 누락 등 실패를 구분한다.
- 최근 조회와 확인한 후보를 브라우저에 저장하고 삭제할 수 있게 한다.
- 비로그인 공개 API와 이미지 분석의 호출량 및 비용 제한을 설정한다.
- 정상 및 실패 응답으로 조회 흐름을 검증한다.

## 조사에서 이어받은 항목

- [API 조사](../api-research.md)에 확인된 개발 한도는 초당 5건, 하루 1,000건이다. 최초 기본 조회 5회와 추가 조회를 합산해 제한하고 서버 캐시 및 중복 요청 합치기를 적용한다.
- 날짜와 프리셋이 다른 응답을 섞지 않는다. 데이터 기준일과 요청 시각을 별도 기록한다.
- API에서 가져온 브라우저 저장 정보에 만료와 재조회 처리를 적용한다. 공식 문서의 30일 이내 갱신 고지를 반영한다.
- 서버 환경에 개발용 키를 설정한 뒤 실응답을 검증한다. 문서 스키마만 확인한 상태를 실연동 완료로 표시하지 않는다.
- 공식 출처 문구 `Data based on NEXON Open API`를 표시한다.

## 구현 결과 (2026-09-10)

- React 기반 장비 조회 화면과 서버 전용 NEXON Open API 프록시를 구현했다.
- 이름 조회, 기본 정보, 능력치, 장비, 세트 효과를 동일한 완료 일자 기준으로 가져온다.
- 개발 단계 호출 한도를 위한 요청 간격, 일일 요청량 파일, 사용자별 분당 제한, 동시 요청 합치기와 15분 캐시를 적용했다.
- 최근 조회는 브라우저에 최대 29일간 보관하며 사용자가 삭제할 수 있다.
- API 키가 없을 때도 화면을 확인할 수 있는 명시적 예시 캐릭터를 제공한다. 강화 추천은 계산 검증 전이므로 미제공 상태로 표시한다.
- 실제 NEXON 응답으로 장비 23개, 세트 6개, 능력치 44개를 파싱했다. API 키와 `ocid`는 클라이언트 응답에 포함하지 않는다.
- 서버 단위 테스트 10개와 데스크톱·모바일 브라우저 흐름 6개, 프로덕션 빌드가 통과했다.

이미지 분석 호출량과 비용 제한은 이미지 기능 구현 티켓에서 제공자 선택 후 추가한다.

### 2026-09-11 장비 표시 보완

- 같은 부위가 반복되어도 장비 배열을 그대로 보존하고 화면 키를 슬롯·이름·순서로 구분한다. 동일한 슬롯명이 반복되면 표시 순번을 붙인다.
- NEXON 장비 응답의 업그레이드 완료 횟수, 남은 횟수, 황금망치, 가위 사용 가능 횟수와 소울 정보를 보존한다.
- 장비 분석 화면을 장비·업그레이드·스타포스·잠재능력으로 분리하고 능력치·세트 효과 보기를 유지한다.
- 스타포스 불가 부위는 장비 목록과 상세에서 별 아이콘을 표시하지 않으며 스타포스 계산 화면에서도 제외한다.
- 캐릭터 요약에 API 전투 스냅샷의 보스 데미지를 추가한다.

### 2026-09-14 일반·캐시 장비 통합

- 일반 장비 조회와 별도의 캐시 장비 조회를 동일 기준일에 호출하고 현재 기본 외형 및 추가 외형 장비를 하나의 장비 목록으로 합친다.
- 캐릭터 최초 조회는 식별자·기본 정보·일반 장비·캐시 장비·능력치·세트 효과의 6회 호출을 사용하며 기존 호출 간격, 일일 한도와 15분 캐시를 그대로 적용한다.
- 캐시 장비의 옵션, 라벨, 만료일, 프리즘, 스킬과 외형 구분을 보존하고 목록 검색·유형 필터·장비 상세에서 표시한다.
- 캐시 장비는 스타포스·잠재능력 대상이 아니므로 강화 분석 및 추천 요청에서는 제외한다.
