# 추천 화면과 공개 전 검증

Status: ready-for-agent
Type: task
Depends on: 03, 04, 05

## 완료 기준

- 보스와 난이도, 예산, 이벤트 선택 및 전체 추천을 제공한다.
- 목표 충족 시 추가 강화 불필요와 전체 추천 진입을 제공한다.
- 대상 장비와 목표, 비용, 예상 최종뎀 증가율, 효율 및 추천 이유를 표시한다. 상세 확률은 펼쳐본다.
- 미검증 직업과 계산 조건을 명시하며 정확한 수치를 지어내지 않는다.
- 조회부터 이미지 확인과 구매 및 강화 비교까지 모바일과 데스크톱에서 검증한다.
- 이미지 미보관, 인증 정보 미노출과 공식 출처 표기를 확인한다.
- 로컬 실행 URL, 검증 결과와 공개에 남은 조건을 기록한다. 실제 배포는 별도 작업이다.

## Comments

### 2026-09-11 구현 진행

- 장비 상세의 잠재능력, 에디셔널 잠재능력, 총 옵션, 기본 옵션, 추가옵션, 업그레이드 증가량과 스타포스 증가량을 접힘 없이 한 영역에 표시한다.
- 관리자 장비 목표의 적용 범위, 현재 상태, 목표 상태, 근거와 규칙 버전을 표시한다.
- 데스크톱과 모바일에서 통합 옵션, 보스 범위 전환과 가로 넘침을 브라우저 테스트로 검증했다.
- 비용·최종뎀·메소당 효율 순위, 구매 비교와 전체 관리자 카탈로그는 아직 완료 기준에 미달하므로 상태를 유지한다.

### 2026-09-11 장비 툴팁 개선

- 첨부된 게임 내 장비 툴팁을 기준으로 스타포스, 장비명, 아이콘, 요구 레벨, 옵션별 강화 기여값, 주문서 강화와 두 잠재능력을 하나의 어두운 패널로 재구성했다.
- NEXON Open API의 장비 설명, 외형, 성별, 성장, 주문서 복구 횟수 필드를 보존하고 외부 이미지 주소는 기존 허용 목록으로 검증한다.
- Open API가 사용한 주문서 이름을 제공하지 않으므로 강화 종류를 추정하지 않고 미제공 상태와 실제 증가 옵션을 함께 표시한다.
- 탭과 계산표는 모바일에서 가로 스크롤 대신 줄바꿈 및 세로형 행을 사용한다.

### 2026-09-11 잠재 등급과 장비 목표 보정

- 게임 내 등급 표현에 맞춰 상세 툴팁의 잠재 마커와 강조색을 레전드리(L)·유니크(U)·에픽(E)·레어(R)로 분리했다.
- 보스 범위에 해당하는 장비군 목표를 여러 부위에 걸쳐 표시하고, 목표를 달성한 장비는 결과에서 제외한다.
