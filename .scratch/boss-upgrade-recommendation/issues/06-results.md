# 추천 화면과 공개 전 검증

Status: ready-for-agent
Type: task
Depends on: 03, 04, 05

## 완료 기준

- 보스와 난이도, 예산, 이벤트 선택 및 전체 추천을 제공한다.
- 목표 충족 시 추가 강화 불필요와 전체 추천 진입을 제공한다.
- 대상 장비와 목표, 비용, 예상 최종뎀 증가율, 효율 및 추천 이유를 표시한다. 상세 확률은 펼쳐본다.
- 미검증 직업과 계산 조건을 명시하며 정확한 수치를 지어내지 않는다.
- 조회부터 이미지 확인과 구매 및 강화 비교까지 모바일과 데스크톱에서 검증한다.
- 이미지 미보관, 인증 정보 미노출과 공식 출처 표기를 확인한다.
- 로컬 실행 URL, 검증 결과와 공개에 남은 조건을 기록한다. 실제 배포는 별도 작업이다.
