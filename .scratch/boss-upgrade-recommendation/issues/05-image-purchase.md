# 이미지와 구매 비교

Status: ready-for-agent
Type: task
Depends on: 02, 03, 04

## 완료 기준

- 장비 하나의 스크린샷에서 장비명, 스타포스, 두 잠재능력, 추가옵션 및 보이는 가격을 추출한다.
- 원본과 추출값을 확인 및 수정한 뒤 비교에 추가한다. 누락과 불확실한 값은 표시하며 수동 입력도 지원한다.
- 가격 누락 시 입력받는다. 가격 없는 교체 목표에 비용 효율 순위를 부여하지 않는다.
- 추가옵션과 세트 효과를 포함한 교체 전체 차이를 계산하고 기존 장비 판매금은 차감하지 않는다.
- 분석 제공자의 보관 정책과 비용을 확인한다. 원본을 분석 후 서버 및 로그에 남기지 않고 외부 전송은 안내한다.
- 오인식 수정, 세트 손실, 가격 누락, 분석 실패와 이미지 정리를 검증한다.
