# 비용과 추천 계산

Status: ready-for-human
Type: task
Depends on: 01, 02, 08

## 완료 기준

- 캐릭터, 목표 보스, 선택적 예산과 이벤트에서 스타포스 및 두 잠재능력 후보를 생성한다.
- 기대 비용, 예상 최종뎀 증가, 메소당 효율과 예산 내 목표 달성 확률을 반환한다.
- 옵션 보존, 실패, 파괴, 복구와 예산 소진 중단 정책을 실제 규칙에 맞춰 계산한다.
- 예산 내 후보 선정 기준을 명시하고 전체 추천도 제공한다. 기대 비용을 성공 보장으로 표현하지 않는다.
- 목표 충족 및 추천 불가 사유를 반환하고 변경 반영 후 재계산한다.
- 확률 기준값, 예산 경계와 강화 불가 사례로 결과를 검증한다.

## 확인된 규칙 반영

- 메소 잠재 재설정은 기존 옵션 선택 보존을 반영한다. 성능 보존 정책에서 목표 미달과 강제 성능 하락을 혼동하지 않는다.
- 잠재 등급 상승 보장은 재설정 방식과 등급별 월드 공유 상태를 확인해 반영한다. 게임의 퀘스트 알림이에 표시되는 보장까지 남은 횟수를 사용자가 입력하지 않으면 공식 최대 횟수를 가정한다.
- 2026 스타포스 개편의 12성 복구 및 별 보존 복구를 구분한다. 복구용 장비 가격이 없으면 파괴를 포함한 정밀 기대비용을 확정하지 않는다.
- 과거 이벤트나 2025 성공률을 현행 최종 확률로 그대로 사용하지 않는다. 근거는 [강화 규칙 조사](../upgrade-rules-research.md)를 따른다.

## Comments

### 2026-09-11 구현 진행

- `전체 추천`과 `예산 내 추천` 모드, 억 메소 단위 예산 입력을 추가했다.
- 추천 요청 스키마와 API를 추가하고 목표 보스, 전투 스냅샷, 장비 정보, 추천 범위 및 정수 메소 예산을 검증한다.
- 현재 장비에서 읽을 수 있는 스타포스·일반 잠재·에디셔널 잠재 정보의 범위를 반환한다.
- 현행 강화 비용·확률과 직업별 보스전 피해 모델이 검증되기 전에는 순위, 비용 또는 최종 데미지 증가율을 반환하지 않는다. UI에서 보스 기준과 계산 모델의 두 차단 사유를 각각 표시한다.
- 실제 추천 계산은 02의 직업별 모델과 08의 강화 수치 데이터에 대한 사람의 검증이 필요하므로 티켓 상태를 `ready-for-human`으로 변경했다.

### 2026-09-11 화면 분리 이후 상태

- 스타포스와 잠재능력의 검증된 참고 계산을 각각의 작업 화면으로 분리했다.
- 스타포스 불가 부위는 후보 생성 단계와 화면에서 동일하게 제외한다.
- 비용만 낮은 행동을 보스전 효율 추천으로 오인하지 않도록 순위 차단을 유지한다. 다음 구현에는 직업별 장비 변경 전후 모델 피해량과 관리자 검증 사례가 필요하다.

### 2026-09-11 관리자 장비 목표 1차 엔진

- 보스 순서 구간, 장비 이름과 목표 강화 상태를 버전이 있는 관리자 카탈로그로 분리했다.
- 현재 장비가 카탈로그 목표에 미달하면 현재 상태, 목표 상태와 이유를 반환한다. 목표 달성 장비와 적용 보스 범위 밖 장비는 추천하지 않는다.
- 합의된 첫 규칙으로 하드 스우 이하에서 `에스텔라 이어링 22성` 목표를 제공하고 익스트림 스우 이상에서는 제외한다.
- 관리자 장비 목표는 메소당 효율 순위와 분리한다. 예산 필터, 구매 비교, 기대 최종뎀은 검증 전 상태를 유지한다.

### 2026-09-11 장비군 목표 확장

- 정확한 장비명뿐 아니라 접두어 기반 장비군을 매칭하고, 같은 장비군의 여러 착용 부위를 각각 평가한다.
- 익스트림 스우 이상 구간의 에테르넬·아스트라 22성 목표와 익스트림 스우부터 익스트림 세렌 구간의 아케인셰이드 22성 목표를 추가했다.
- 아스트라 보조무기는 스타포스 후보로 포함하고 `special_ring_level`이 있는 특수 링은 후보에서 제외한다.
- 이는 목표 상태 추천의 첫 범위이며, 기대 최종뎀과 메소당 효율 순위는 검증 전 차단 상태를 유지한다.

### 2026-09-11 잠재 옵션 줄 등급 판정

- 장비의 전체 잠재 등급을 세 줄에 그대로 적용하지 않고, 같은 부위·레벨·잠재 종류의 NEXON 공식 하위 등급 첫 번째 옵션표와 실제 옵션 문자열을 비교한다.
- 레전드리 장비의 유니크 옵션, 유니크 장비의 에픽 옵션, 에픽 장비의 레어 옵션을 줄별로 구분한다. 레어는 추가 조회 없이 레어로 판정한다.
- 판정 결과는 장비 상세에 줄별 색으로 표시하며 서버 캐시, 동일 요청 합치기와 IP별 요청 제한을 적용한다.

### 2026-09-11 일반 직업군 장비 목표

- NEXON 공식 랭킹에는 환산 전투력 순위가 없고 외부 환산 사이트의 자동 수집은 허용되지 않아, 첫 범위는 직업과 무관하게 적용할 수 있는 장비 슬롯 및 장비군 기준으로 구성했다.
- 노멀 스우는 스타포스 가능한 Lv.130 이상 장비 17성, 하드 스우는 18성을 공통 기준으로 사용한다. 특수 스킬 반지는 제외한다.
- 루타비스, 여명, 칠흑, 아케인셰이드, 에테르넬 및 아스트라처럼 장기 사용 장비군은 보스 구간별 22성 목표를 별도로 적용한다.
- 한 장비에 공통 기준과 장비군 기준이 겹치면 더 높은 스타포스 목표 하나만 반환한다. 이는 구매 가격과 최종 데미지를 반영한 효율 순위가 아니다.

### 2026-09-12 공식 랭킹 장비 표본 파이프라인

- `npm run refresh:equipment-baselines`로 NEXON 공식 종합 랭킹의 직업별 장비 사용 분포를 갱신할 수 있다.
- 기본 3명, 최대 10명씩 48개 최종 직업을 동일하게 조회하고 기존 NEXON 호출 간격과 프로세스 간 잠금이 적용된 일일 호출량 파일을 공유한다.
- 한 직업이라도 요청 표본보다 성공 수가 적으면 기존 스냅샷을 교체하지 않는다.
- 캐릭터 이름과 OCID를 저장하지 않고 직업·슬롯·아이템 사용 수만 집계한다.

### 2026-09-12 직업별 장비 사용 참고

- 기존 전체 상위 무릉 표본 대신 NEXON 공식 종합 랭킹의 48개 최종 직업별 동일 표본을 사용한다.
- 추천 요청에 캐릭터 직업을 포함하고, 일치하는 직업 표본의 현재 착용 부위별 상위 관측 장비를 최대 3개까지 반환한다.
- 화면에는 관측 횟수, 현재 장비 일치 여부, 표본 수, 기준일과 데이터 버전을 표시한다.
- 관측 빈도는 가격·성능·강화 우선순위가 아니므로 관리자 장비 목표 및 메소당 효율 순위와 분리한다.

### 2026-09-12 보스용 장비 프리셋 선택

- NEXON 장비 응답의 프리셋 1~3을 모두 정규화하고 현재 적용 프리셋 번호와 별개로 보스 분석용 프리셋을 선택한다.
- 경험치, 아이템 드롭률과 메소 획득량 관련 장비명·설명·잠재 옵션이 있는 프리셋은 우선 제외한다.
- 남은 프리셋은 보스 관련 잠재와 장비 총옵션을 비교한다. 직업별 최종뎀 모델이 아니므로 화면에는 보스 옵션 기반 자동 선택으로 표시한다.
- 모든 프리셋에 사냥 옵션이 있으면 장비를 비우지 않고 사냥 옵션 종류가 가장 적은 후보를 사용하며 사냥 옵션 포함 상태를 표시한다.

### 2026-09-14 비용 우선 추천과 표본 품질

- 캐시 전용 필터를 제거하고 NEXON 응답의 전투 추가 옵션이 하나 이상 있는 캐시 장비만 일반 장비 목록에 합친다.
- 스타포스 목표는 현재 별부터 목표 별까지 각 단계의 파괴·복구 기대 비용을 합산하고, 목표 별 1개당 기대 메소가 낮은 순서로 정렬한다. 스페어 구매가는 포함하지 않는다.
- 일반 잠재는 사냥 옵션을 제외하고 직업 주스탯, 무기류 공격력·마력·보스 데미지·방어율 무시, 장갑 크리티컬 데미지와 모자 재사용 대기시간 감소를 보스전 유효 줄로 판정하여 3줄 미만을 추천한다.
- 공식 연습모드의 전체 보스와 제공 난이도를 선택 목록에 추가한다. 솔로 클리어 전투력 수치는 공식 기준이 없으므로 검증 전 상태를 유지한다.
- 직업별 랭킹 표본 기본값을 8명으로 올리고 각 표본에서 사냥 프리셋이 아닌 가장 강한 보스 프리셋을 선택한다. 직업당 8명 미만인 기존 스냅샷은 화면에 노출하지 않는다.
- 2026-09-14에는 개발 키의 실제 NEXON 일일 호출량이 소진되어 384명 스냅샷 재생성을 완료하지 못했다. 원자적 교체 정책으로 기존 파일은 보존했으며 다음 호출량 초기화 후 재실행해야 한다.

### 2026-09-15 예산 제외 사유와 평균 비용 안내

- 예산 모드에서 전체 후보 수, 선택 수, 비용 미확인 제외 수, 남은 예산 초과 제외 수, 기대 지출과 잔여 예산을 반환한다.
- 비용 미확인 후보는 전체 추천으로 전환하면 확인할 수 있으며, 예산 결과가 비어도 강화가 불필요하다고 단정하지 않는다.
- 기대 비용은 평균이며 예산 내 성공 보장이나 예산 내 성공 확률이 아님을 명시한다. 실제 성공 확률과 최종뎀 효율은 검증 전 상태를 유지한다.
- 예산 초과 집계는 비용순 후보를 순차 선택한 시점의 남은 예산 기준이다. 최적 배낭 해라고 표현하지 않는다.

### 2026-09-15 에디셔널 목표 후보 확장

- 윗잠과 에디셔널 세 줄을 추천 API로 전달하고 각각 독립적으로 3줄 목표를 생성한다. 결과에 잠재 종류를 명시한다.
- 기존 직업별 주스탯·무기류 보스전 옵션 판정에 더해 에디셔널 방어구의 고정 공격력·마력과 레벨당 주스탯 문구를 판정한다. 줄 수는 최종뎀 증가량이나 옵션별 동등 가치가 아니다.
- 에디셔널 옵션이 모두 미제공이면 0줄로 추정하지 않는다. 특수 링은 제외하고 미지원 등급은 목표를 생성하지 않는다.
- 비용·최종뎀 미검증을 후보 이유에 표시하고 기대 비용은 null로 유지한다. 예산 모드에서는 비용 미확인 후보로 집계한다.
- 코드 규칙·요구사항 검토에서 확인한 상속 속성 이름의 미지원 등급 우회 문제를 수정하고 회귀 테스트를 추가했다. 단위 테스트 97개, 브라우저 테스트 20개 및 빌드가 통과했다.
