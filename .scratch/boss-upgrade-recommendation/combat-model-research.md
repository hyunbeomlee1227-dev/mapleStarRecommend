# 보스 목표와 전투 모델 조사

확인일: 2026-09-10. 백그라운드 조사는 사용량 제한으로 완료되지 않아, 공식 메이플스토리 가이드에서 직접 확인한 범위만 기록한다.

## 확인한 사실

- 공식 보스 가이드는 보스 UI에서 보스와 난이도를 선택한다고 설명한다. 연습모드 목록에는 스우부터 유피테르까지 보스별 지원 난이도가 정리되어 있다. [보스 콘텐츠 진행 방법](https://maplestory.nexon.com/guide/n23gameinformation/articles/458)
- 앱의 초기 목표 목록은 공식 연습모드 목록 가운데 스우 이상 구간을 사용한다. 목록 마지막의 유피테르 하드를 기본 선택으로 두지만, 공식 문서가 이를 명시적으로 '최종 보스'라고 정의한 것은 아니다. 관리자 순서가 검증되면 별도 버전으로 갱신한다.
- 공식 스탯 가이드는 데미지와 보스 데미지는 합 연산, 최종 데미지와 방어율 무시는 곱 연산이라고 설명한다. 크리티컬 데미지는 기본 크리티컬 증가량에 더해진다. [전투력과 특수 스탯](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/390)
- 같은 가이드는 스탯 공격력이 주요·보조 스탯, 공격력 또는 마력, 데미지, 최종 데미지, 무기 상수와 숙련도에 따라 달라진다고 설명한다. 공개 페이지에는 전 직업의 장비 변경 전후 보스 피해를 완전히 재현하는 단일 공식이 제공되지 않는다.
- 버프와 소비 아이템은 같은 장비에서도 능력치를 크게 바꿀 수 있다. 따라서 API의 현재 스냅샷만으로 솔로 클리어를 보장할 수 없다. [버프로 강해지기](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/451)

## 구현 결정

- 현재 API 스냅샷에서 최대 스탯공격력, 데미지, 보스 데미지, 최종 데미지, 방어율 무시와 크리티컬 데미지를 구조화하고 누락 여부를 판정한다.
- 공식 설명만으로 전 직업 예상 최종뎀을 계산하지 않는다. 직업별 스킬, 버프 조건과 보스 방어율 및 포스 조건을 검증한 뒤 계산기를 활성화한다.
- 보스 목표 목록과 관리자 솔로 기준은 분리한다. 목록은 공식 출처로 제공할 수 있지만 모든 기준은 현재 `pending`이며 목표 충족 판정에 사용하지 않는다.
- 관리자 기준에는 근거 링크, 갱신일과 버전이 필수다. 검증 전 화면은 '기준 검증 중' 상태를 반환한다.

## 남은 조사

- 보스별 방어율, 포스, 레벨, 페이즈와 제한 시간의 최신 공식 수치.
- 신규 보스까지 포함한 난이도 순서 및 기본 최상위 목표의 관리자 승인.
- 전 직업의 상시·극딜 버프 조건과 장비 옵션 변화에 대한 검증 사례.
- 연무장 동일 조건 전후 기록을 활용한 모델 오차 검증.
