# 한국 메이플스토리 강화 규칙 조사

조사 기준일: 2026-09-09 (KST). 넥슨 한국 본서버 공식 가이드·업데이트·이벤트 본문만 근거로 사용했다. 커뮤니티 글, 테스트월드 수치, 해외 서버 자료는 제외했다. API 목록은 조사하지 않았다. '확인'은 해당 공식 본문에서 확인했다는 뜻이며, 전체 후속 패치의 부재까지 증명한다는 뜻은 아니다.

## 2026-09-11 재확인

- 2026-04-16 공식 복구 공지는 당시 현재/최대 레벨 기준 잠재 재설정 비용으로 일반 250레벨 레어/에픽/유니크/레전드리 500만/2,000만/4,250만/5,000만 메소, 에디셔널 1,225만/3,430만/8,330만/9,800만 메소를 사용했다. 기존 비용표의 250~300 구간과 일치한다. 출처: [동일 잠재옵션 등장 오류 복구 안내](https://maplestory.nexon.com/news/notice/notice/148947).
- 공식 확률 페이지는 현재도 재설정 방식별 등급 상승 확률과 월드 공유 보장 횟수를 게시한다. 목표 옵션은 부위·레벨·등급별 표와 공식 중복 제한을 반영하고, 낮은 등급에서는 목표 등급까지의 상승 비용과 사용자가 입력한 보장 잔여 횟수를 함께 계산한다. 출처: [일반 잠재](https://maplestory.nexon.com/Guide/OtherProbability/cube/black), [에디셔널 잠재](https://maplestory.nexon.com/Guide/OtherProbability/cube/addi).
- 구현된 규칙 레지스트리에서 잠재 재설정 1회 비용만 검증 상태로 공개한다. 목표 옵션 확률은 부분 검증, 스타포스 기대 비용과 직업별 피해 모델은 미지원으로 차단한다.

## 부모 작업 인계: 손실 위험 가정 수정

조사 단계 인계 완료. API 매핑은 부모 작업 결과를 사용하며, 아래 수치 대기는 이번 단계의 종료를 막지 않는다.

- **메소 잠재 재설정은 기존 결과를 선택해 보존할 수 있다.** 일반·에디셔널 모두 새 옵션이 나쁘다고 기존 옵션을 반드시 잃는 구조가 아니다. 시도 비용은 별도로 계산해야 한다. [일반](https://maplestory.nexon.com/news/update/737), [에디셔널](https://maplestory.nexon.com/News/Update/746).
- **스타포스 파괴는 기존 잠재 전체의 영구 소실이 아니다.** 확인된 잠재와 다른 강화 정보가 흔적에 저장된다. 복구 전 사용 불가와 복구 재료·메소 부담을 모델링해야 하며, 미확인 잠재는 예외다. [현재 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/412).
- **일반 장비 실패 시 별 하락은 없으며, 파괴 후에도 12성 복구만 가능한 것이 아니다.** 2026 개편 대상 흔적은 비용을 지불해 저장된 별로 복구할 수 있다. 23성 이상 시도 중 파괴는 22성 저장, 구형 흔적·슈페리얼은 예외다. [개편 공지](https://maplestory.nexon.com/news/update/799).
- **수치 확인 대기:** 현행 스타포스 최종 확률, 기본 강화·별 보존 복구 메소표/산식, 옵션별 조합 확률, 최신 이벤트 세부 조건. 확보 전에는 정확한 기대비용을 확정하지 않는다.

## 1. 스타포스: 확인된 현재 규칙

- 일반 장비는 모든 단계에서 실패에 따른 별 하락이 없다. 현재 14성 이하에서는 파괴도 없으며, 15성 이상에서는 파괴될 수 있다. 파괴 방지는 현재 15~17성에서 선택 가능하다.
- 일반 장비 최대치는 착용 레벨 ~94/95~107/108~117/118~127/128~137/138 이상 순서로 5/8/10/15/20/30성이다. 슈페리얼은 별도 규칙이며 하락 방지·파괴 방지가 없고 5성부터 파괴 가능하다.
- 흔적에는 일반·에디셔널 잠재, 주문서 강화, 추가옵션, 소울, 교환 조건이 보존된다. **미확인 잠재는 보존되지 않는다.** 흔적은 교환 불가다.

출처: [현재 스타포스 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/412).

- 2026-03-19부터 스타캐치가 삭제되고 기존 스타캐치 성공 보정이 항상 적용된다.
- 신규 흔적은 파괴 직전 별을 저장하되, 23성 이상에서 강화 도중 파괴되면 22성으로 저장된다. 2026-03-19 점검 전 흔적 및 슈페리얼에는 이 변경이 적용되지 않는다.
- 별 보존 복구는 레벨·별에 따른 메소와 동일 장비를 요구한다. 흔적 ~18성/19~20성/21성/22성에 장비 1/2/3/4개가 필요하다. 동일 장비 1개로 12성 기본 복구도 선택 가능하다.
- 제로 8형 이상은 에센스 추가 요구, 아스트라는 장비 1개와 별도 메소, 데스티니 2차 초월은 장비 1개와 별도 메소 또는 제로용 에센스라는 예외가 있다. 일반 장비 복구 비용으로 대체하면 안 된다.

출처: [2026-03-19 강화 개편](https://maplestory.nexon.com/news/update/799).

## 2. 일반·에디셔널 잠재 확률

메소 재설정 기준. 보장 횟수는 공식 표의 명칭과 숫자를 그대로 요약했다.

| 등급 상승 | 일반 확률 | 일반 보장 횟수 | 에디셔널 확률 | 에디셔널 보장 횟수 |
|---|---:|---:|---:|---:|
| 레어 → 에픽 | 약 15% (*) | 10 | 2.3810% | 62 |
| 에픽 → 유니크 | 3.5000% | 42 | 0.9804% | 152 |
| 유니크 → 레전드리 | 1.4000% | 107 | 0.7000% | 214 |

- (*) 조회한 일반 공식 페이지는 `15.0000001275%`로 표기한다. 정확도 차이를 임의 정정하지 않았으며 내부 정밀 확률인지 표기 문제인지는 미확인이다.
- 보장은 연속 등급 상승 실패에 적용되며, 재설정 방식별·등급별로 저장되어 월드 내 캐릭터가 공유한다. 특정 장비만의 카운터로 모델링하면 안 된다. 게임은 퀘스트 알림이에서 보장에 필요한 남은 횟수를 제공하며, 보장 외 등급 상승에도 수치가 초기화된다. 출처: [2023-04-20 본서버 업데이트](https://maplestory.nexon.com/News/Update/704).
- 첫 줄은 현재 등급 100%. 일반 둘째/셋째 줄이 현재 등급일 확률은 20%/5%, 나머지는 한 단계 아래다.
- 에디셔널 둘째·셋째 줄이 현재 등급일 확률은 각각 레어 1.9608%, 에픽 4.7619%, 유니크 1.9608%, 레전드리 0.4975%다.
- 에디셔널 큐브/화이트 에디셔널 큐브의 레어→에픽 4.7619%, 에픽→유니크 1.9608%는 **메소 재설정 확률과 다르다**.

출처: [일반 공식 확률](https://maplestory.nexon.com/Guide/OtherProbability/cube/black), [에디셔널 공식 확률](https://maplestory.nexon.com/Guide/OtherProbability/cube/addi).

### 옵션 조합과 보존

- 두 공식 확률 페이지는 등급·장비 분류·레벨별 옵션 검색을 제공한다. 특정 주스탯/공격력/보공 조합의 확률은 이 조사에서 검색 결과 전체를 추출하지 못했다. 줄 등급 확률을 옵션 등장 확률로 사용하면 안 된다.
- 공식 페이지에는 쓸만한 스킬·피격 후 무적시간 계열 최대 1개, 일부 피격 데미지 무시·무적 계열 최대 2개 제한과 제외 옵션에 대한 확률 재정규화가 명시되어 있다. 세 줄을 무조건 독립으로 곱할 수 없다. 직전과 완전히 같은 결과는 다시 추첨한다. 출처: [일반](https://maplestory.nexon.com/Guide/OtherProbability/cube/black), [에디셔널](https://maplestory.nexon.com/Guide/OtherProbability/cube/addi).
- 메소 일반·에디셔널 재설정은 기존 결과와 새 결과 중 선택 가능하다. 이는 기존 옵션 묶음 보존이며 특정 줄 고정 기능으로 해석하지 않는다. 출처: [일반 도입](https://maplestory.nexon.com/news/update/737), [에디셔널 도입](https://maplestory.nexon.com/News/Update/746).
- 동일 옵션 재등장 오류는 2026-04-16 공식 복구 공지가 존재한다. 출처: [오류·복구 안내](https://maplestory.nexon.com/news/notice/notice/148947).

## 4. 이벤트·할인

### 2026-09-15 파괴 방지 계산 조건

- 일반 장비 현재 15~17성에서 기본 시도 비용 외에 할인 전 기본 비용의 200%를 추가한다. 출처: [1.2.401 업데이트](https://maplestory.nexon.com/News/Update/767).
- 앱은 성공률을 그대로 두고 실패 시 장비가 유지되는 `destroy-to-maintain` 모델을 사용한다. 파괴 방지 동작과 현행 하락 없음 규칙에 따른 해석이며 공식 재배분 수치표를 확보했다는 뜻은 아니다.
- MVP·PC방 할인은 기본 시도 비용에만 적용하며 방지 추가 비용과 온전 복구 비용에는 적용하지 않는다. 현재 선택한 조건은 추천 API 추적 정보에 남긴다.

### 2026-09-15 상시 혜택 재검증

- MVP 스타포스 할인은 실버 3%, 골드 5%, 다이아·레드·블랙 10%이며 17성 도달까지 적용된다. 슈페리얼은 제외한다. 출처: [MVP 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/425).
- 프리미엄 PC방 할인은 5%이며 17성 도달까지 적용된다. 슈페리얼은 제외하고 MVP 할인과 함께 받을 수 있다. 출처: [PC방 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/444).

## 8. 레전드리 목표 잠재 조합 계산 (2026-09-12)

- 일반 및 에디셔널 공식 페이지는 쓸만한 스킬 계열과 피격 후 무적시간 증가를 세 줄 중 합계 최대 1개로 제한한다.
- 피격 시 일정 확률로 데미지 무시 및 무적 옵션은 세 줄 중 합계 최대 2개로 제한한다.
- 제한 수에 도달하면 이후 줄에서 해당 그룹을 제외하고 남은 표기 확률로 재정규화한다.
- 현재 잠재와 완전히 동일한 세 줄 결과는 다시 추첨하므로, 현재 결과의 확률을 전체 표본공간과 목표 성공 확률에서 함께 제외한다.
- 공식 표의 반올림 오차는 각 줄 합계를 1로 정규화한 뒤 순차 열거한다. 계산 결과는 1회 목표 성공 확률, 평균 재설정 횟수와 현재 등급의 1회 비용을 곱한 기대 메소로 제공한다.
- 등급 상승과 옵션 조합이 동시에 달라지는 레전드리 미만 장비는 아직 지원하지 않으며 추천용 capability는 `partial`을 유지한다.

## 9. 낮은 등급의 목표 잠재 계산 (2026-09-14)

- 현재 등급부터 사용자가 선택한 목표 등급까지 각 단계의 공식 등급 상승 확률과 등급별 메소 비용을 연결한다.
- 목표 등급에 도달한 재설정 결과도 해당 등급의 공식 옵션표를 따르므로, 마지막 등급 상승 시도에서 목표가 나오지 않은 경우에만 추가 목표 옵션 재설정 비용을 더한다.
- 현재 등급과 목표 등급이 같을 때만 현재 세 줄과 완전히 동일한 결과의 재추첨을 조건부 확률에 반영한다. 다른 등급으로 상승한 결과는 현재 결과와 동일할 수 없으므로 제외하지 않는다.
- 월드 공유 보장 상태는 API 스냅샷에서 알 수 없으므로 사용자가 퀘스트 알림이에 표시된 등급별 남은 횟수를 입력한다. 남은 마지막 시도는 확정 상승으로, 그 전에는 해당 시도에서 절단된 기하분포로 계산한다. 입력하지 않은 등급은 공식 표의 전체 보장 횟수로 처리하며 capability는 이벤트·추천 목표 자동 선정이 남아 `partial` 및 추천 사용 불가를 유지한다.
