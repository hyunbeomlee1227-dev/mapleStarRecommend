# 보스전 강화 우선순위 추천 앱

Status: ready-for-agent

## Problem Statement

한국 메이플스토리 이용자는 보스전 성능을 높이기 위해 스타포스, 일반 잠재능력, 에디셔널 잠재능력, 장비 구매 중 어디에 메소를 먼저 투자해야 하는지 판단하기 어렵다. 현재 장비, 캐릭터 전체 능력치, 목표 보스 난이도, 예산, 강화 실패와 파괴 위험, 세트 효과까지 함께 비교해야 하지만 직접 입력하고 계산하는 과정은 번거롭고 오류가 발생하기 쉽다.

사용자는 같은 메소로 가장 큰 보스전 성능 증가를 얻는 다음 행동을 알고 싶다. 공식 데이터로 검증되지 않은 비용, 확률, 직업별 피해량 또는 솔로 클리어 기준을 정확한 값처럼 제공해서는 안 된다.

## Solution

회원가입 없이 캐릭터 이름을 조회하면 NEXON Open API에서 보스전에 사용할 일반 장비 프리셋과 현재 캐시 장비, 능력치를 가져와 하나의 장비 목록으로 보여준다. 사용자는 보스와 난이도를 각각 선택하고, 예산 제한 없는 전체 추천 또는 억 메소 단위의 예산 내 추천을 선택한다.

서비스는 스타포스, 일반 잠재능력, 에디셔널 잠재능력 및 구매 후보를 동일한 전투 조건에서의 예상 보스전 최종 데미지 증가율과 기대 메소 비용으로 비교한다. 결과는 효율, 기대 비용, 위험, 목표 상태와 근거 버전을 함께 보여준다. 필요한 공식 규칙이나 직업별 계산 모델이 검증되지 않은 경우 수치를 추정하지 않고 계산 불가 사유와 분석 가능한 데이터 범위를 표시한다.

구매 비교는 경매장 자동 수집 대신 아이템 툴팁 이미지 OCR 또는 수동 입력을 사용한다. 사용자는 추출 결과를 확인하고 수정한 후 비교에 추가하며 원본 이미지는 분석 후 서버에 보관하지 않는다.

## User Stories

1. As a 한국 메이플스토리 이용자, I want 캐릭터 이름으로 현재 장비를 조회하고 싶다, so that 장비 정보를 일일이 입력하지 않아도 된다.
2. As a 비회원 사용자, I want 회원가입 없이 서비스를 사용하고 싶다, so that 계정 생성 없이 바로 강화 방향을 확인할 수 있다.
3. As a 사용자, I want 경험치·아이템·메소 획득 세팅을 제외한 보스용 장비 프리셋과 조회 기준일을 확인하고 싶다, so that 사냥 세팅을 강화 대상으로 잘못 분석하지 않는다.
4. As a 사용자, I want 현재 스타포스와 일반·에디셔널 잠재능력을 한 화면에서 보고 싶다, so that 장비 상태를 빠르게 점검할 수 있다.
5. As a 사용자, I want 장비를 검색하고 잠재 등급으로 필터링하고 싶다, so that 원하는 장비를 빠르게 찾을 수 있다.
6. As a 사용자, I want 장비의 추가옵션과 스타포스 증가량을 확인하고 싶다, so that 추천 근거가 되는 원본 상태를 검토할 수 있다.
7. As a 사용자, I want 적용 중인 세트 효과를 확인하고 싶다, so that 장비 교체로 발생하는 세트 변화를 이해할 수 있다.
8. As a 사용자, I want 목표 보스와 난이도를 별도로 선택하고 싶다, so that 같은 보스의 서로 다른 난이도를 명확하게 구분할 수 있다.
9. As a 사용자, I want 선택한 보스에서 지원하는 난이도만 보고 싶다, so that 존재하지 않는 조합을 선택하지 않게 된다.
10. As a 사용자, I want 선택한 목표가 새로고침 후에도 유지되길 원한다, so that 조건을 다시 입력하지 않아도 된다.
11. As a 목표를 선택하지 않은 사용자, I want 지원 목록의 최상위 보스가 기본 적용되길 원한다, so that 즉시 분석을 시작할 수 있다.
12. As a 사용자, I want 모든 추천을 보고 싶다, so that 예산과 무관하게 장기 강화 방향을 검토할 수 있다.
13. As a 예산이 정해진 사용자, I want 억 메소 단위로 예산을 입력하고 싶다, so that 보유 자금 안에서 후보를 비교할 수 있다.
14. As a 사용자, I want 잘못된 예산 입력을 즉시 안내받고 싶다, so that 잘못된 조건으로 계산하지 않게 된다.
15. As a 사용자, I want 스타포스와 두 종류의 잠재능력을 같은 기준으로 비교하고 싶다, so that 메소당 효율이 가장 높은 행동을 고를 수 있다.
16. As a 사용자, I want 장비 구매 후보도 강화 후보와 비교하고 싶다, so that 기존 장비 강화보다 교체가 유리한지 판단할 수 있다.
17. As a 사용자, I want 구매 후보의 추가옵션과 세트 효과 변화를 포함하고 싶다, so that 교체 효과를 누락하지 않는다.
18. As a 사용자, I want 기존 장비 판매금을 구매 비용에서 자동 차감하지 않길 원한다, so that 불확실한 회수 금액이 효율을 왜곡하지 않는다.
19. As a 사용자, I want 예상 최종 데미지 증가율을 보고 싶다, so that 서로 다른 강화 수단의 보스전 효과를 비교할 수 있다.
20. As a 사용자, I want 예상 최종 데미지가 동일 조건의 전후 피해량 차이라는 설명을 확인하고 싶다, so that 게임 내 최종 데미지 스탯과 혼동하지 않는다.
21. As a 사용자, I want 기대 비용과 예산 내 성공 확률을 구분해서 보고 싶다, so that 평균 비용을 성공 보장 금액으로 오해하지 않는다.
22. As a 사용자, I want 실패, 파괴, 복구와 예산 소진 위험을 확인하고 싶다, so that 위험을 감수할지 판단할 수 있다.
23. As a 사용자, I want 기존 잠재 결과를 유지할 수 있는 메소 재설정 규칙이 반영되길 원한다, so that 존재하지 않는 옵션 손실을 가정하지 않는다.
24. As a 사용자, I want 강화 이벤트 조건을 선택하고 싶다, so that 적용 가능한 할인과 확률 변화를 비교할 수 있다.
25. As a 사용자, I want 목표 보스에 충분한 상태라면 추가 강화가 불필요하다는 결과를 보고 싶다, so that 과투자를 피할 수 있다.
26. As a 사용자, I want 목표를 충족해도 전체 추천을 볼 수 있길 원한다, so that 장기 성장 방향을 검토할 수 있다.
27. As a 사용자, I want 관리자 목록 밖 장비도 실제 성능이 충분하면 인정받길 원한다, so that 인기 장비 목록에만 종속되지 않는다.
28. As a 사용자, I want 추천마다 대상 장비, 현재 상태, 목표 상태, 비용, 성능 증가, 효율과 이유를 보고 싶다, so that 실행 여부를 결정할 수 있다.
29. As a 사용자, I want 선택한 변경을 적용한 상태로 다시 계산하고 싶다, so that 한 단계씩 다음 투자 방향을 확인할 수 있다.
30. As a 사용자, I want 아이템 툴팁 이미지를 올려 구매 후보를 입력하고 싶다, so that 복잡한 옵션을 직접 타이핑하지 않아도 된다.
31. As a 사용자, I want OCR 결과의 불확실한 값과 누락값을 확인하고 수정하고 싶다, so that 잘못 읽힌 값으로 추천받지 않는다.
32. As a 개인정보를 중시하는 사용자, I want 업로드한 원본 이미지가 서버에 남지 않길 원한다, so that 불필요한 데이터 보관을 피할 수 있다.
33. As a 사용자, I want 확인한 장비와 비교 후보가 브라우저에 저장되길 원한다, so that 회원가입 없이 작업을 이어갈 수 있다.
34. As a 미지원 직업의 사용자, I want 계산 불가 사유를 명확히 보고 싶다, so that 검증되지 않은 숫자를 신뢰하지 않는다.
35. As a 사용자, I want 공식 수치가 부족하면 분석 가능한 장비 범위를 보고 싶다, so that 확보된 데이터와 부족한 데이터를 구분할 수 있다.
36. As a 사용자, I want 사용한 규칙과 관리자 기준의 버전 및 갱신일을 확인하고 싶다, so that 오래된 기준인지 판단할 수 있다.
37. As a 모바일 사용자, I want 조회부터 추천 조건 입력까지 작은 화면에서 수행하고 싶다, so that 데스크톱 없이 이용할 수 있다.
38. As a 공개 서비스 운영자, I want API 키가 브라우저에 노출되지 않길 원한다, so that 인증 정보 오용을 방지할 수 있다.
39. As a 공개 서비스 운영자, I want 조회 제한과 캐시가 적용되길 원한다, so that 외부 API 한도와 서비스 안정성을 보호할 수 있다.
40. As a 사용자, I want 선택된 보스용 일반 장비 프리셋과 현재 착용한 모든 캐시 장비를 한 번에 조회하고 싶다, so that 분석 대상 장비와 캐시 외형을 빠뜨리지 않고 확인할 수 있다.
40. As a 공개 서비스 운영자, I want 근거 없는 임계값과 강화 확률이 배포되지 않길 원한다, so that 잘못된 투자 추천으로 사용자를 오도하지 않는다.

## Implementation Decisions

- 서비스 대상은 한국 메이플스토리이며 사냥 성능은 제외하고 솔로 보스전만 평가한다.
- 브라우저는 프런트엔드만 제공하고 NEXON Open API 인증과 조회는 서버가 담당한다. API 키는 클라이언트 응답, 로그 및 번들에 포함하지 않는다.
- 캐릭터 기본 정보, 일반 장비, 캐시 장비, 최종 능력치와 세트 효과를 동일 기준일의 스냅샷으로 정규화한다. 날짜가 일치하지 않으면 분석을 중단한다.
- 일반 장비와 캐시 장비의 기본·추가 외형 목록을 공통 장비 모델로 합치되 전투 추가 옵션이 있는 캐시 장비만 노출한다. 원본 캐시 옵션, 라벨, 만료일, 프리즘과 스킬 정보를 보존하고 캐시 장비는 강화 추천 계산에서 제외한다.
- 장비 프리셋 1~3에서 경험치·아이템 드롭률·메소 획득량 관련 장비와 잠재 옵션이 있는 프리셋을 먼저 제외하고, 남은 후보는 보스 데미지·방어율 무시·크리티컬 데미지·공격/마력·스탯 옵션 기반으로 선택한다. 모든 프리셋이 사냥 옵션을 포함하면 가장 적게 포함한 후보임을 명시한다.
- 공개 API 계약은 캐릭터 조회, 보스 목표 목록, 목표 충족 판정, 강화 추천과 강화 규칙 상태의 다섯 경계로 유지한다.
- 보스 목표는 고유 ID, 보스, 난이도, 순서, 출처, 기준 상태, 버전, 갱신일과 근거를 갖는 관리자 데이터다.
- 목표 UI는 보스와 난이도의 종속 선택이다. 보스 변경 시 같은 난이도가 있으면 유지하고 없으면 해당 보스의 가장 높은 등록 난이도를 선택한다.
- 기본 목표는 지원 목록의 마지막 최상위 항목이다. 이를 게임사가 선언한 최종 보스라고 표현하지 않는다.
- 선택한 목표, 최근 조회와 비교 후보는 브라우저에 저장한다. 저장소 접근 실패가 핵심 조회 기능을 중단하지 않는다.
- 전투 스냅샷은 스탯 공격력, 데미지, 보스 데미지, 최종 데미지, 방어율 무시, 크리티컬 수치, 전투력과 포스를 읽는다. 누락 또는 파싱 실패를 0으로 처리하지 않는다.
- 예상 최종 데미지 증가율은 동일 조건의 변경 전후 모델 피해량 비율이며 게임 내 최종 데미지 능력치와 구분한다.
- 직업별 계산 모델은 지원 상태와 검증 사례를 가진다. 검증되지 않은 직업에는 정밀 수치나 순위를 반환하지 않는다.
- 보스별 솔로 클리어 기준은 관리자 추정치이며 공식 보장으로 표현하지 않는다. 검증 전 목표는 대기 상태로 유지한다.
- 추천 요청은 목표 ID, 전체 또는 예산 모드, 정수 메소 예산, 전투 스냅샷과 최소 장비 정보를 받는다.
- 예산 UI는 억 메소 단위를 사용하고 서버에는 양의 안전한 정수 메소로 전달한다. 전체 추천에는 예산이 필요하지 않다.
- 추천 엔진은 스타포스, 일반 잠재, 에디셔널 잠재와 구매를 공통 출력 단위인 기대 비용, 예상 성능 증가와 메소당 효율로 비교한다.
- 직업별 피해 모델이 미검증이면 최종 데미지 증가율과 메소당 성능 효율을 만들지 않는다. 공식 확률과 출처가 공개된 비용식으로 계산 가능한 스타포스는 스페어 구매가·이벤트를 제외한 참고 기대 비용과 별당 비용순을 제공하고 한계를 함께 표시한다.
- 스타포스는 성공, 유지, 파괴, 파괴 방지, 흔적 복구, 동일 장비 가격과 이벤트 조건을 버전별 상태 전이로 계산한다. MVP·PC방 상시 할인은 17성 도달까지 적용하며 슈페리얼과 특수 장비를 일반 규칙으로 대체하지 않는다.
- 잠재 모델은 재설정 비용, 등급 상승, 보장 카운터, 줄 등급, 옵션 조합 제한과 기존 결과 선택 보존을 구분한다.
- 기대 비용은 평균값이며 성공 보장 금액으로 표시하지 않는다. 예산 모드는 예산 소진 전 목표 도달 확률을 별도로 계산한다.
- 구매 후보는 OCR과 수동 입력을 지원한다. 가격 없는 후보의 구매 효율 순위는 확정하지 않는다.
- OCR 결과는 사용자 확인 전 계산에 사용하지 않으며 불확실한 값과 누락값을 표시한다.
- 업로드 원본 이미지는 분석 후 서버에 보관하지 않는다. 외부 제공자를 쓰면 전송 및 보관 조건을 알린다.
- 선택한 변경 후 상태로 추천을 다시 계산한다. 여러 변경의 예산 배분 최적화는 후속 기능이다.
- 추천 결과는 실제 솔로 클리어 또는 강화 성공을 보장하지 않으며 넥슨 공식 서비스가 아님을 표시한다.

## Testing Decisions

- 가장 높은 테스트 경계는 공개 API와 실제 브라우저 사용자 흐름이다. 내부 구현보다 입력에 대한 응답과 화면 동작을 검증한다.
- 서버 계약 테스트는 유효한 입력, 잘못된 목표, 누락된 전투 스냅샷, 잘못된 예산, 장비 개수 제한과 미검증 모델 차단을 검증한다.
- 캐릭터 조회 테스트는 동일 날짜 정규화, 빈 장비, 일반·캐시 장비 통합, 업스트림 오류, 캐시, 동시 요청 병합, 속도 제한, 일일 한도와 인증 정보 비노출을 검증한다.
- 전투 모델 테스트는 능력치 파싱, 필수 능력치 누락, 미지원 직업, 보스 기준 미검증과 근거 없는 피해량 생성 방지를 검증한다.
- 강화 규칙 테스트는 버전별 공식 기준값으로 확률 합계, 단계 경계, 파괴와 복구, 보장 카운터, 이벤트 중첩과 예산 경계를 검증한다.
- 추천 테스트는 결정성, 강화 유형 간 비교, 목표 충족, 추천 불가 이유와 변경 적용 후 재계산을 검증한다.
- 구매 비교 테스트는 추가옵션, 세트 변화, 가격 누락, 목록 밖 장비 인정과 기존 장비 판매금 미차감을 검증한다.
- OCR 테스트는 오인식 수정, 불확실성 표시, 확인 전 계산 차단, 실패와 원본 미보관을 검증한다.
- 브라우저 테스트는 데스크톱과 모바일에서 조회, 보스·난이도 선택, 선택 유지, 장비 탐색, 추천 모드 전환, 예산 검증과 실패 상태를 검증한다.
- 시각 검증은 전체 화면 스크린샷으로 텍스트 잘림, 요소 겹침, 가로 스크롤과 잘못된 고정 위치를 확인한다.
- 기존 서버 계약 테스트와 Playwright 사용자 흐름을 선행 사례로 사용하고 새 기능도 이 두 경계에 추가한다.
- 실제 API 검증은 응답 구조와 분석 준비 상태까지만 확인한다. 실제 캐릭터 수치를 고정 테스트 기대값으로 사용하지 않는다.

## Out of Scope

- 사냥, 경험치와 아이템 획득 효율 추천
- 자동 강화, 게임 클라이언트 조작 또는 자동 구매
- 경매장 매물 자동 수집과 실시간 시세 크롤링
- 기존 장비 판매 예상금의 자동 차감
- 추가옵션 재설정 자체의 투자 추천
- 검증되지 않은 직업의 정확한 피해량과 강화 순위
- 실제 보스 처치 시간과 솔로 클리어 보장
- 여러 강화 행동에 예산을 자동 배분하는 전역 최적화
- 회원가입, 계정 동기화와 서버 기반 사용자 프로필
- 사용자가 확인하지 않은 OCR 결과의 자동 적용

## Further Notes

- 공식 데이터 조사와 실제 응답 검증을 구분한다. 확인되지 않은 값은 커뮤니티 계산식이나 과거 수치로 대체하지 않는다.
- 스타포스 현행 확률은 공식 수치로 검증하고 기본 메소 산식은 메수라이브 공개 모델을 비공식 출처로 구분한다. 스페어 가격·복구 비용·이벤트 조건이 없는 참고 기대값은 제공하되 정밀 추천에는 사용하지 않는다.
- 잠재 재설정 비용과 일부 등급 확률은 공식 근거가 있으나 목표 옵션 조합 확률과 중복 제한을 검증한 뒤에만 기대 비용에 사용한다.
- 버프와 전투 조건은 API 스냅샷에 완전히 표현되지 않을 수 있으므로 관리자 솔로 기준과 사용자 결과에 불확실성을 표시한다.
- 현재 구현은 전투 옵션 캐시 장비 통합 조회, 게임형 장비 툴팁과 옵션별 강화 기여값, 업그레이드·스타포스·잠재능력 비교 보기, 중복 부위 보존, 스타포스 불가 부위 제외, 보스 데미지 표시, 공식 연습모드 보스·난이도 선택, 전투 스냅샷, 목표 판정 상태, 전체·예산 추천 입력, 잠재 등급 상승 비용·확률과 사용자 입력 보장 잔여 횟수, 부위·레벨·등급별 공식 잠재 옵션표, 목표 스타까지의 누적 기대 메소와 별당 비용 정렬, MVP·PC방 상시 할인과 15~17성 파괴 방지, 슈페리얼 비용 계산 제외, 보스전 유효 윗잠 3줄 후보, 보스 구간별 장비 목표를 제공한다. 직업별 랭킹 장비 참고는 보스 프리셋 기준 직업당 8명 이상 스냅샷이 완성된 경우에만 노출한다.
- 작업 순서와 세부 티켓은 같은 기능 디렉터리의 작업 목록과 구현 이슈를 따른다.
