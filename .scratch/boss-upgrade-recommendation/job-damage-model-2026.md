# 전 직업 보스전 장비 변경 효과 계산 모델 조사

- 조사 기준일: 2026-09-11 (KST)
- 대상: 한국 메이플스토리
- 출처 제한: `maplestory.nexon.com`, `gi.maplestory.nexon.com`, `openapi.nexon.com`의 넥슨 공식 자료만 사용
- 조사 질문: 공식 자료만으로 전 직업의 가상 장비 변경 전후 보스전 피해량을 정확히 계산할 수 있는가?

## 결론

**현재 공개된 공식 자료만으로는 전 직업의 가상 장비 변경 전후 보스전 피해량을 정확히 계산할 수 없다.**

공식 가이드는 스탯 공격력이 주요/보조 스탯, 공격력 또는 마력, 데미지, 최종 데미지, 무기 상수, 무기 숙련도의 영향을 받는다고 설명하고, 데미지·보스 데미지·최종 데미지·방어율 무시·크리티컬 데미지의 연산 방식 일부를 공개한다. 그러나 스탯 공격력의 완전한 수치식, 전 직업 보조스탯 표, 무기별 상수값, 직업별 특수 변환식, 스킬별 보스 전투 모델을 하나의 최신 공식 사양으로 공개하지 않는다. [전투력과 특수 스탯](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/390)

따라서 현재 공식 자료만으로 가능한 것은 다음 범위다.

1. 현재 장비와 최종 능력치 스냅샷을 공식 Open API에서 조회한다.
2. 장비의 표시 옵션과 세트 효과가 어떻게 달라지는지 비교한다.
3. 사용자가 실제로 장비를 교체한 뒤 다시 조회하거나 연무장 기록을 남기면, 공식 시스템이 계산한 전후 결과를 **관측값**으로 비교한다.
4. 아직 착용하지 않은 구매 후보나 강화 목표의 보스전 최종 데미지 증가율을 전 직업에 대해 정확한 값으로 예측하는 것은 불가능하다.

이 결론은 “계산 자체가 영구히 불가능하다”는 뜻이 아니다. 비공개 공식을 임의로 사실로 간주하지 않고, 직업별 입력 데이터와 통제된 연무장 A/B 검증 데이터를 확보해 **관리자 검증 모델**로 제공해야 한다는 뜻이다.

## 정확 계산의 의미

이 앱에서 구분해야 할 계산 수준은 세 가지다.

| 수준 | 의미 | 공식 자료만으로 가능한가 |
| --- | --- | --- |
| 장비 옵션 차이 | STR, 공격력, 보스 데미지, 방어율 무시, 세트 효과 등의 표시값 차이 | 가능 |
| 가상 장비 변경 후 최종 능력치 | 후보를 실제 착용하지 않은 상태에서 게임 내 최종 스탯을 재현 | 전 직업 정확 계산 불가 |
| 보스전 피해/DPS 변화 | 스킬 구성, 버프, 재사용 대기시간, 보스 조건과 가동률까지 반영한 전후 피해 비율 | 전 직업 정확 계산 불가 |

게임 내 전투력 역시 여러 능력치를 이용한 “보정된 수치”라고 설명될 뿐 웹 문서에는 완전한 산식이 없고, 상세 정보는 게임 내 전투력 도움말에서 확인하도록 안내한다. 전투력을 공식 피해 공식의 대체물로 사용할 수 없다. [전투력과 특수 스탯](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/390)

## 공식 공통 공식의 공개 범위

### 공개된 내용

- 데미지와 보스 몬스터 데미지는 합 연산이다.
- 최종 데미지는 곱 연산이다.
- 방어율 무시는 곱 연산이며 특정 스킬에만 적용되는 값은 최종 능력치 표시에 포함되지 않을 수 있다.
- 크리티컬 확률은 합 연산이고 최대 100%까지 적용된다.
- 크리티컬 데미지는 기본 크리티컬 증가 범위에 더해진다.
- 재사용 대기시간 감소는 % 감소 후 고정 감소를 적용하며, 10초 이하 구간과 5초 하한에 별도 규칙이 있다.
- 스탯 공격력에 주요/보조 스탯, 공격력/마력, 데미지, 최종 데미지, 무기 상수와 무기 숙련도가 관여한다.

근거: [전투력과 특수 스탯](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/390)

캐릭터와 몬스터의 레벨 차이에 따른 데미지 배율은 공식 표로 공개되어 있다. [레벨별 데미지 공식](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/377)

아케인포스와 어센틱포스 지역의 주는 피해 비율도 공식 표와 식으로 공개되어 있다. 다만 이 자료만으로 각 보스의 모든 페이즈와 현재 요구 포스 조건까지 자동 확정할 수 있는 것은 아니다. [아케인포스/어센틱포스](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/396)

### 공개되지 않았거나 불완전한 내용

- 일반 직업과 특수 직업을 모두 포괄하는 스탯 공격력의 완전한 수치식
- 주요스탯과 보조스탯의 계수 및 적용 순서
- 무기 종류별 무기 상수의 최신 공식 숫자표
- 스킬별로 별도 적용되는 데미지, 최종 데미지, 방어율 무시의 완전한 적용 규칙
- 공격력/마력 %, 올스탯 %, HP %, 심볼 스탯 등 서로 다른 원천의 적용 순서와 예외를 포괄하는 공식 사양
- 소환수, 도트, 파이널 어택, 추가타, 게이지, 변신, 태그, 스킬 연계와 재사용 대기시간이 포함된 직업별 지속 피해 공식
- 보스별 레벨, 방어율, 속성 내성, 포스, 페이즈 전환, 무적 시간과 실제 공격 가능 시간을 한 번에 제공하는 최신 기계 판독형 공식 데이터

공식 가이드도 특정 스킬 전용 수치가 일반 최종 능력치 연산에 포함되지 않는다고 명시한다. 최종 능력치 스냅샷만으로 모든 스킬의 실제 피해를 복원할 수 없다는 직접적인 제한이다. [전투력과 특수 스탯](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/390)

## 직업별 공개 범위

### 주요스탯: 공개

공식 직업소개에는 조사 시점의 48개 직업 상세 페이지가 연결되어 있고 각 페이지에 `주요스탯`과 `사용무기`가 표시된다. [직업소개](https://maplestory.nexon.com/Guide/N23Job)

| 공식 주요스탯 | 직업 |
| --- | --- |
| STR | 히어로, 팔라딘, 다크나이트, 소울마스터, 미하일, 블래스터, 데몬 슬레이어, 아란, 카이저, 아델, 렌, 제로, 바이퍼, 캐논슈터, 스트라이커, 은월, 아크 |
| DEX | 보우마스터, 신궁, 패스파인더, 윈드브레이커, 와일드헌터, 메르세데스, 카인, 캡틴, 메카닉, 엔젤릭버스터 |
| INT | 아크메이지(불,독), 아크메이지(썬,콜), 비숍, 플레임위자드, 배틀메이지, 에반, 루미너스, 일리움, 라라, 키네시스, 레테 |
| LUK | 나이트로드, 섀도어, 듀얼블레이드, 나이트워커, 팬텀, 카데나, 칼리, 호영 |
| HP | 데몬 어벤져 |
| STR, DEX, LUK | 제논 |

대표적으로 히어로는 STR과 여러 검·도끼를, 데몬 어벤져는 HP와 데스페라도·포스 실드를, 제로는 STR과 알파/베타의 서로 다른 전용 무기를, 제논은 STR·DEX·LUK와 에너지 소드를 표시한다. [히어로](https://maplestory.nexon.com/Guide/N23Job/View/1), [데몬 어벤져](https://maplestory.nexon.com/Guide/N23Job/View/8), [제로](https://maplestory.nexon.com/Guide/N23Job/View/12), [제논](https://maplestory.nexon.com/Guide/N23Job/View/34)

### 보조스탯: 전 직업 최신 표 미공개

현재 공식 직업소개 상세 페이지에는 `주요스탯`과 `사용무기`는 있지만 `보조스탯` 필드는 없다. 공식 스탯 가이드는 보조스탯이 스탯 공격력 계산에 쓰인다고만 설명한다. 조사 범위에서는 전 직업의 최신 보조스탯과 계수를 한데 명시한 공식 표를 찾지 못했다. [직업소개](https://maplestory.nexon.com/Guide/N23Job), [전투력과 특수 스탯](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/390)

데몬 어벤져 출시 안내처럼 개별 과거 공식 업데이트에 “주스탯 HP, 부스탯 STR”이 명시된 사례는 있다. 그러나 이런 단편 자료는 전 직업의 현행 통합 사양이 아니며 이후 변경 여부까지 보장하지 않는다. [데몬 어벤져 업데이트](https://maplestory.nexon.com/news/update/265)

### 무기 종류: 공개, 무기 상수: 수치 미공개

공식 직업소개는 직업별 사용무기를 공개한다. 그러나 공식 스탯 가이드는 “무기 상수”가 스탯 공격력에 관여한다고만 밝히고 무기별 숫자를 제공하지 않는다. 따라서 사용무기 정보만으로 무기 교체의 정확한 피해 변화를 계산할 수 없다. [직업소개](https://maplestory.nexon.com/Guide/N23Job), [전투력과 특수 스탯](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/390)

### 무기 숙련도: 관측·스킬 설명은 가능, 통합 공식은 미공개

공식 가이드는 무기 숙련도가 스탯 공격력에 관여하며 게임 내 스탯 공격력 툴팁에서 확인할 수 있다고 설명한다. 직업 스킬 설명과 Open API의 스킬 정보로 개별 캐릭터의 숙련도 관련 스킬을 확인할 수 있지만, 전 직업·전 무기 조합을 포괄하는 최신 숫자표와 피해 적용식은 별도 공개되지 않았다. [전투력과 특수 스탯](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/390), [스킬 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/401)

### 특수 예외: 존재와 일부 효과만 공개

공식 자료에서 확인되는 대표 예외는 다음과 같다.

- 데몬 어벤져: 주요스탯이 HP이고, 공식 출시 안내는 AP로 투자한 HP와 현재 HP 상태가 공격력에 영향을 준다고 설명한다. 그러나 현행 전체 변환식은 제공하지 않는다. [직업소개](https://maplestory.nexon.com/Guide/N23Job/View/8), [데몬 어벤져 업데이트](https://maplestory.nexon.com/news/update/265)
- 제논: 주요스탯이 STR·DEX·LUK 세 종류다. 공식 심볼 업데이트도 제논에게 세 스탯을 함께 지급하는 별도 수치를 사용한다. 하지만 세 스탯의 공격력 환산식을 공개하지 않는다. [직업소개](https://maplestory.nexon.com/Guide/N23Job/View/34), [심볼 능력치 업데이트](https://maplestory.nexon.com/News/Update/662)
- 제로: 알파와 베타를 교체해 싸우고 서로 다른 전용 무기를 사용한다. 단일 무기·단일 상태 모델로 계산할 수 없다. [직업소개](https://maplestory.nexon.com/Guide/N23Job/View/12)
- 팬텀은 다른 직업의 스킬을 훔쳐 사용할 수 있고, 제논은 일부 도적·해적 장비와 스킬을 사용하며, 여러 직업이 게이지·변신·연계·소환수 구조를 가진다. 공식 직업소개는 이런 구조를 설명하지만 장비 변화가 전체 보스 딜 사이클에 미치는 수치식을 제공하지 않는다. [직업소개](https://maplestory.nexon.com/Guide/N23Job)

즉, 특수 예외는 “존재 여부”와 일부 스킬 효과는 공개되어 있으나 정확한 전 직업 계산기를 구현할 정도로 정규화된 공식 모델은 아니다.

## NEXON Open API로 확보 가능한 데이터

공식 Open API는 한국 메이플스토리 데이터를 제공하며 평균 약 15분 뒤 확인할 수 있다고 안내한다. 캐릭터 기본 정보, 종합 능력치, 장비, 심볼, 세트 효과, 스킬, 링크 스킬, V매트릭스, HEXA 코어·스탯, 기타 능력치 영향 요소 등을 각각 조회할 수 있다. [메이플스토리 Open API](https://openapi.nexon.com/ko/game/maplestory/)

이 API는 다음 목적에는 유효하다.

- 현재 적용 중인 최종 능력치와 장비 상태를 동일 기준일 스냅샷으로 수집
- 장비별 기본·추가·주문서·스타포스·잠재·에디셔널·총 옵션 수집
- 적용 세트, 심볼, 링크, V/HEXA, 어빌리티와 기타 효과의 현재 상태 기록
- 실제 장비 교체 후 새로운 공식 계산 결과를 재조회하여 전후 관측값 비교

하지만 API가 최종 결과와 구성 요소를 제공한다는 사실은 비공개 계산식을 제공한다는 뜻이 아니다. 현재 스냅샷 하나만으로 가상 후보 장비의 새 최종 능력치나 스킬별 피해를 역산할 수 없다. 특히 공식 가이드상 특정 스킬 전용 효과는 일반 능력치 표시에 포함되지 않을 수 있다. [전투력과 특수 스탯](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/390)

또한 버프 스킬과 소비 아이템은 같은 장비에서도 능력치를 크게 바꿀 수 있으므로 조회 시점의 버프 조건을 통제하지 않으면 전후 비교가 오염된다. [버프로 강해지기](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/451)

## 공식 연무장 데이터의 활용 가능성

공식 연무장은 1인 전투 시뮬레이션으로, 체력이 무한한 연습용 몬스터, 전용 버프, 직업별 필수 핵심 스킬 사용 횟수, 총 전투 시간, 총 데미지, DPS와 스킬 사용 내역을 제공한다. [연무장 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/144565)

2026-04-02부터 Open API에는 연무장 측정 결과, 스킬 사용 내역, 입장 시점 캐릭터 능력치 관련 정보 조회가 추가되었다. 능력치 정보는 리플레이 등록 시점을 기준으로 한다. [연무장 Open API 추가 공지](https://openapi.nexon.com/ko/support/notice/3414787/)

연무장은 공식 공식을 대신 공개하지는 않지만, 관리자 모델의 검증 데이터로는 가장 신뢰도가 높은 공식 관측 경계다. 다만 플레이어 조작, 스킬 적중, 공격 간격과 무작위 요소가 결과에 영향을 주므로 한 번의 리플레이만으로 장비 효과를 확정해서는 안 된다.

## 전 직업 계산에 필요한 입력

### 1. 캐릭터 현재 상태

- 직업, 레벨, 적용 프리셋과 기준 시각
- STR, DEX, INT, LUK, HP, MP의 기본값·고정 증가·% 증가·최종 적용값
- 공격력/마력의 기본값·고정 증가·% 증가·최종 적용값
- 데미지, 보스 데미지, 최종 데미지, 방어율 무시, 크리티컬 확률·데미지
- 재사용 대기시간 감소·미적용, 버프 지속시간, 속성 내성 무시, 상태이상 추가 데미지
- 아케인포스, 어센틱포스, 심볼별 스탯과 특정 보스 대상 추가 효과
- 장비, 세트 효과, 소울, 심볼, 펫 장비, 안드로이드, 칭호, 훈장
- 하이퍼 스탯, 어빌리티, 링크, 유니온·아티팩트, V매트릭스, HEXA 코어·스탯
- 소비 아이템, 길드·이벤트·연무장 전용 버프를 포함한 적용 버프 목록

### 2. 변경 후보 상태

- 교체 전후 장비의 모든 옵션을 같은 필드로 정규화한 값
- 장비 레벨·종류·무기 종류·보조무기·스타포스·주문서·추가옵션·잠재·에디셔널
- 교체로 활성화·비활성화되는 세트 효과와 럭키 아이템 규칙
- 무기 교체 시 직업별 착용 가능 여부, 공격력/마력 선택, 무기 상수와 숙련도 변화
- 쿨다운 감소, 특정 스킬 강화, 소환수/파이널 어택 강화처럼 최종 능력치만으로 표현되지 않는 옵션

### 3. 직업별 모델 데이터

- 현행 주요스탯과 보조스탯 목록 및 각 계수
- HP·복수 스탯·알파/베타 등 특수 스탯 공격력 변환식
- 무기별 상수, 숙련도, 보조무기와 이도류 처리
- 공격 스킬별 퍼뎀, 타수, 공격 간격, 재사용 대기시간, 지속시간과 적용 대상 수
- 스킬별 추가 데미지·최종 데미지·방어율 무시·크리티컬·속성·방어율 적용 규칙
- 패시브, 온·오프, 변신, 게이지, 스택, 연계, 소환수, 도트, 추가타와 재사용 대기시간 상호작용
- V/HEXA 강화와 직업별 공용 스킬 적용 규칙
- 솔로 보스 기준의 표준 딜 사이클, 버프 순서와 측정 시간

### 4. 보스 환경 데이터

- 보스·난이도·페이즈별 레벨, 방어율, 속성 내성, 요구 포스
- 포스 배율과 특정 심볼의 특정 보스 추가 데미지 효과
- 페이즈별 체력, 회복, 제한 시간, 무적·이동·패턴으로 인한 실제 공격 가능 시간
- 상태이상 적용 가능 여부와 직업별 조건부 효과 발동 여부
- 솔로 기준에서 사용할 생존·부활·버프 조건

## 필요한 검증 데이터와 절차

공식 수치표가 없는 항목은 다음과 같은 통제된 데이터를 확보한 뒤 관리자 검증 모델로만 사용해야 한다.

1. **직업별 기준 캐릭터 구성 고정**
   장비 프리셋, 하이퍼, 어빌리티, 링크, 유니온, 심볼, V/HEXA, 버프와 키 입력 조건을 고정하고 버전과 시각을 기록한다.

2. **단일 변수 A/B 장비 쌍 수집**
   한 번에 하나의 축만 바뀌는 장비 쌍을 준비한다. 최소 축은 고정 주스탯, 주스탯 %, 올스탯 %, 공격력/마력, 공격력/마력 %, 보스 데미지, 방어율 무시, 크리티컬 데미지, 쿨다운 감소다. 데몬 어벤져는 HP 관련 축, 제논은 STR·DEX·LUK 개별·동시 축, 제로와 이도류 직업은 무기 조합 축을 별도로 둔다.

3. **공식 전후 스냅샷 저장**
   각 A/B 상태에서 Open API의 종합 능력치, 장비, 세트, 스킬, 링크, V/HEXA와 기타 영향 요소를 같은 조건으로 저장한다. API 반영 지연 때문에 교체 직후 값이 아니라 기준 시각이 일치하는지 확인한다. [메이플스토리 Open API](https://openapi.nexon.com/ko/game/maplestory/)

4. **연무장 반복 측정**
   동일한 전용 버프와 필수 스킬 조건에서 A/B 리플레이를 여러 번 수집하고 총 데미지, DPS, 스킬별 사용량·피해와 입장 능력치를 함께 저장한다. 결과가 조작 편차에 민감하므로 반복 측정의 분산과 이상치를 기록한다. [연무장 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/144565), [연무장 Open API 추가 공지](https://openapi.nexon.com/ko/support/notice/3414787/)

5. **교차 검증**
   같은 직업에서 장비 수준과 능력치 분포가 다른 여러 캐릭터를 사용하고, 모델 작성에 쓰지 않은 A/B 쌍으로 예측 오차를 검증한다. 직업별·옵션별 허용 오차는 제품 운영 기준으로 사전에 정해야 하며 공식 보장치로 표현하지 않는다.

6. **패치 버전 격리**
   스킬·장비·보스 규칙 변경 시 이전 검증을 자동 승계하지 않는다. 공식 업데이트 날짜, 클라이언트 버전, 모델 버전과 검증 데이터 버전을 함께 저장하고 영향 직업을 재검증한다.

## 권장 지원 상태

| 기능 | 권장 상태 | 이유 |
| --- | --- | --- |
| 현재 장비·최종 능력치 표시 | 지원 | 공식 API 관측값 |
| 장비 표시 옵션과 세트 변화 비교 | 지원 | 공식 장비·세트 데이터로 비교 가능 |
| 실제 교체 후 전후 최종 능력치 비교 | 지원 | 두 공식 관측 스냅샷 비교 |
| 미착용 후보의 전후 최종 능력치 예측 | 부분 지원 또는 미지원 | 완전한 공식 직업식·무기 상수·예외 부족 |
| 미착용 후보의 보스전 최종 데미지 증가율 | 미지원 | 스킬·보스·딜 사이클 모델까지 불완전 |
| 전 직업 강화 효율 순위 | 미지원 | 비용뿐 아니라 직업별 피해 변화 검증이 선행되어야 함 |
| 직업별 관리자 검증 모델 | 검증 완료 직업만 제한 지원 | 연무장 A/B 교차 검증과 버전 관리가 필요 |

`부분 지원`을 사용자에게 노출할 때는 옵션 증가량이나 공식 관측값만 보여주고, 이를 “예상 최종 데미지” 또는 “정확한 강화 순위”로 표현해서는 안 된다. `지원` 전환 조건은 해당 직업의 입력 완전성, 특수 예외 목록, 통제된 A/B 검증과 패치 버전 재검증을 모두 통과하는 것이다.

## 제품 구현에 대한 판정

1. 모든 직업의 `주요스탯` 분류는 공식 직업소개를 기준으로 등록할 수 있다.
2. `보조스탯`, `무기 상수`, `특수 변환식`은 공식 수치가 없다는 이유로 커뮤니티 표를 그대로 공식 데이터처럼 등록해서는 안 된다.
3. Open API의 현재 `최대 스탯공격력`, `보스 몬스터 데미지`, `최종 데미지`, `방어율 무시`, `크리티컬 데미지`만으로 가상 장비 변경 효과를 정확히 역산해서는 안 된다.
4. 우선 제공 가능한 안전한 결과는 장비 옵션 차이, 세트 변화, 공식 스냅샷 완전성, 직업 모델의 검증 상태다.
5. 실제 피해 증가율과 메소당 효율은 직업별 관리자 모델이 연무장 검증을 통과한 경우에만 활성화해야 한다.
6. 전 직업 동시 활성화보다 공통 입력 스키마를 먼저 만들고, 일반 직업군과 데몬 어벤져·제논·제로 등 특수 모델을 분리하여 직업별로 검증 상태를 승격하는 방식이 타당하다.
