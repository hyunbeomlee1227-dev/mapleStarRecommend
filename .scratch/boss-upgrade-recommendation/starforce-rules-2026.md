# KMS 일반 장비 스타포스 규칙 조사 (2026-09-11)

## 조사 범위와 판정 기준

- 대상은 한국 메이플스토리 정식 서버의 **일반 스타포스 장비**다. 슈페리얼 장비, 놀라운 장비강화 주문서, 전용 재화를 쓰는 이벤트 장비, 테스트월드 규칙은 제외한다.
- 출처는 메이플스토리 공식 홈페이지의 정식 서버 업데이트, 공지사항, 게임 가이드만 사용했다. 공식 홈페이지 안의 자유게시판·토론게시판도 사용자 작성 자료이므로 사용하지 않았다.
- `공개`는 공식 문서에 수치가 직접 적힌 경우, `계산`은 공식 공개값과 공식 계산 규칙으로 산출한 경우, `미확인`은 공식 1차 출처에서 현재 수치나 산식을 확인하지 못한 경우를 뜻한다.
- 이 문서는 2026-09-11 현재 공개된 자료를 기준으로 한다. 2026-03-19 이후 스타캐치가 삭제되고 기존 스타캐치 성공 효과가 상시 적용된다. [정식 서버 업데이트, 2026-03-19 적용](https://maplestory.nexon.com/news/update/799)

## 결론 요약

1. 15~29성의 스타캐치 적용 전 확률은 2025-03-20 정식 서버 업데이트에 공개되어 있다. [정식 서버 업데이트, 2025-03-20 적용](https://maplestory.nexon.com/News/Update/767)
2. 2026-03-19부터 스타캐치는 삭제되었고, 스타캐치 성공 시의 확률 상승 효과가 상시 적용된다. [정식 서버 업데이트, 2026-03-19 적용](https://maplestory.nexon.com/news/update/799)
3. 넥슨은 스타캐치 성공 시 성공 확률이 원래 확률의 1.05배가 되며, 15성에서는 성공 31.5%, 유지 66.45%, 파괴 2.06%라고 설명했다. [공식 공지, 계산 규칙 및 예시 공개 2021-02-19](https://maplestory.nexon.com/News/Notice/Notice/133192)
4. 따라서 아래 15~29성 현재 확률은 2025년 공개 확률에 위 1.05배 규칙을 적용한 **계산값**이다. 15성은 공식 예시와 직접 일치하며, 나머지는 같은 규칙을 적용한 산출값이다.
5. 0~14성은 현재 공식 텍스트 자료에서 단계별 성공률 표를 확인하지 못했다. 파괴되지 않는다는 규칙만 확인되므로 성공·유지 확률은 미확인으로 남긴다. [공식 게임 가이드, 2026-09-11 확인](https://gi.maplestory.nexon.com/Guide/GameInformation/ItemEnhancement/StarforceEnforcement)
6. 기본 강화 메소의 절대 산식 또는 전체 레벨·별 구간 표는 확인한 공식 1차 출처에 공개되어 있지 않다. 2025년 공지는 일부 구간의 비용 증가만, 가이드는 메소 사용 사실만 밝힌다. 따라서 커뮤니티에서 유통되는 산식을 채택하지 않는다. [정식 서버 업데이트, 2025-03-20 적용](https://maplestory.nexon.com/News/Update/767), [공식 게임 가이드, 2026-09-11 확인](https://gi.maplestory.nexon.com/Guide/GameInformation/ItemEnhancement/StarforceEnforcement)

## 0~29성 성공·유지·파괴 확률

### 계산 방법

2025년 표의 성공·유지·파괴 확률을 각각 `S`, `M`, `D`라고 할 때 현재 성공률은 `S' = S x 1.05`로 계산했다. 성공률 증가 후 남은 실패 확률을 기존 유지·파괴 비율대로 나누는 식은 다음과 같다.

```text
S' = S x 1.05
M' = M x (100 - S') / (100 - S)
D' = D x (100 - S') / (100 - S)
```

이 해석은 넥슨이 직접 제시한 15성 예시 `30.00 / 67.90 / 2.10 -> 31.5 / 66.45 / 2.06`과 일치한다. [공식 공지, 2021-02-19](https://maplestory.nexon.com/News/Notice/Notice/133192) 2026-03-19 업데이트가 이 스타캐치 성공 효과를 상시 적용한다고 명시했으므로 현재 표에 적용했다. [정식 서버 업데이트, 2026-03-19 적용](https://maplestory.nexon.com/news/update/799)

## 기본 강화 메소 비용

### 확인된 사실

- 스타포스 강화는 메소를 사용하며, 단계별 성공률과 비용은 게임 내 강화 UI에서 확인하는 구조다. [공식 게임 가이드, 2026-09-11 확인](https://gi.maplestory.nexon.com/Guide/GameInformation/ItemEnhancement/StarforceEnforcement)
- 2025-03-20부터 17~19성 및 21성에서 소모되는 메소가 증가했다. 다만 공지는 증가 후 절대 금액이나 산식을 싣지 않았다. [정식 서버 업데이트, 2025-03-20 적용](https://maplestory.nexon.com/News/Update/767)
- 장비의 착용 레벨에 따라 최대 강화 가능 별 수가 달라진다. 착용 레벨 제한 138 이상 장비는 2025-03-20부터 최대 30성까지 강화할 수 있다. [정식 서버 업데이트, 2025-03-20 적용](https://maplestory.nexon.com/News/Update/767)

### 미확인

- 장비 레벨과 현재 별을 입력해 기본 소모 메소를 얻는 **공식 산식**: 미확인.
- 장비 레벨별·현재 별별 **공식 전체 비용표**: 미확인.
- 반올림 단위, 최소 비용, 구간별 상수: 미확인.

따라서 현재 구현용 규칙 데이터에는 기본 메소 비용을 `unverified`로 유지해야 한다. 공식 1차 출처가 없는 커뮤니티 계산식이나 해외 서버 공식을 한국 정식 서버 공식값으로 취급하면 안 된다.

## 파괴 방지

### 적용 구간과 비용

- 2025-03-20 정식 서버 업데이트에서 17성 장비에도 파괴 방지를 적용할 수 있게 되었고, 파괴 방지 **추가 비용**은 기본 강화 메소의 100%에서 200%로 증가했다. 즉 할인·이벤트를 배제한 명목상 총 시도 비용은 `기본 비용 + 기본 비용의 200% = 기본 비용의 300%`다. [정식 서버 업데이트, 2025-03-20 적용](https://maplestory.nexon.com/News/Update/767)
- 같은 업데이트에서 파괴가 발생하는 시작 구간이 15성이고 17성 적용이 “추가”되었다고 명시하므로, 일반 장비의 통상 파괴 방지 구간은 현재 별 15~17성으로 해석된다. 18성 이상 적용 확대는 확인되지 않았다. [정식 서버 업데이트, 2025-03-20 적용](https://maplestory.nexon.com/News/Update/767)
- 공식 가이드는 파괴 방지 선택 시 추가 메소를 소모하고 장비 파괴를 막는다고 설명한다. [공식 게임 가이드, 2026-09-11 확인](https://gi.maplestory.nexon.com/Guide/GameInformation/ItemEnhancement/StarforceEnforcement)

| 현재 별 | 파괴 방지 | 추가 비용 | 총 명목 비용 | 방지 적용 시 파괴 확률 |
|---:|---|---:|---:|---:|
| 15성 | 가능 | 기본 비용의 200% | 기본 비용의 300% | 0% |
| 16성 | 가능 | 기본 비용의 200% | 기본 비용의 300% | 0% |
| 17성 | 가능 | 기본 비용의 200% | 기본 비용의 300% | 0% |
| 그 외 | 공식 확대 근거 없음 | 해당 없음 | 기본 비용 | 원래 확률 |

파괴 방지 시 성공률이 유지되고 파괴분이 유지 결과로 합쳐지는지에 대한 현재 공식 수치표는 찾지 못했다. “파괴를 막는다”는 동작은 확인되지만, 결과 확률의 내부 재배분을 구현하려면 게임 UI 캡처 등 추가 공식 근거가 필요하다.

## 파괴 후 별 보존과 흔적 복구

### 별 보존 규칙

- 2026-03-19 이후 일반 장비가 스타포스 강화 중 파괴되면 흔적 아이템의 스타포스가 **파괴 직전 스타포스 수치**로 설정된다. 다만 23성 이상 강화 도중 파괴된 경우 흔적은 22성으로 설정된다. 이 변경은 슈페리얼 장비와 2026-03-19 점검 전에 이미 획득한 흔적에는 적용되지 않는다. [정식 서버 업데이트, 2026-03-19 적용](https://maplestory.nexon.com/news/update/799)

| 파괴가 발생한 시도 | 생성 흔적의 별 | 판정 |
|---|---:|---|
| 15성→16성 시도부터 22성→23성 시도 | 파괴 직전 별 | 공개 |
| 23성→24성 이상 시도 | 22성 | 공개 |

### 온전한 복구에 필요한 동일 장비 수

흔적의 착용 레벨 제한과 스타포스 수치에 따른 메소 및 동일 장비를 지불하면 흔적의 별을 온전히 복구할 수 있다. 공식 공지가 공개한 동일 장비 수는 다음과 같다. [정식 서버 업데이트, 2026-03-19 적용](https://maplestory.nexon.com/news/update/799)

| 흔적 스타포스 | 동일 장비 필요 수량 | 추가 메소 |
|---:|---:|---:|
| 18성 이하 | 1개 | 미확인 |
| 19~20성 | 2개 | 미확인 |
| 21성 | 3개 | 미확인 |
| 22성 | 4개 | 미확인 |

공식 공지는 일반 장비의 복구 메소가 흔적의 착용 레벨 제한과 스타포스 수치에 따라 달라진다고 설명하지만, 절대 금액 표나 산식을 제공하지 않는다. 따라서 일반 장비의 온전한 복구 메소 비용은 미확인이다. [정식 서버 업데이트, 2026-03-19 적용](https://maplestory.nexon.com/news/update/799)

### 12성 복구 대안

- 동일한 장비 아이템 1개만 지불하여 12성으로 복구하는 대안이 있다. [정식 서버 업데이트, 2026-03-19 적용](https://maplestory.nexon.com/news/update/799)
- 해당 문구가 별도의 메소까지 요구하는지, 요구한다면 얼마인지는 공식 업데이트 본문에서 명확하지 않으므로 미확인이다.

### 특수 장비 예외

제로 라피스/라즐리, 아스트라 보조무기, 데스티니 2차 초월 무기는 장비 수량·에센스·추가 메소에 별도 예외가 있다. 이는 일반 장비 공통 규칙이 아니므로 본 문서의 비용표에는 합치지 않았다. 예외의 원문은 [2026-03-19 정식 서버 업데이트](https://maplestory.nexon.com/news/update/799)에서 확인할 수 있다.

## 구현에 사용할 수 있는 범위

### 검증됨 또는 공식값으로 계산 가능

- 일반 장비 15~29성의 현재 성공·유지·파괴 확률: 공식 2025 원표와 공식 1.05배 규칙으로 계산 가능.
- 일반 장비 0~14성의 파괴 확률: 0%.
- 파괴 방지 가능 구간: 현재 별 15~17성.
- 파괴 방지 추가 비용 배수: 기본 비용의 200%; 총 명목 비용은 기본 비용의 300%.
- 파괴 시 흔적 별 보존 규칙과 온전한 복구에 필요한 동일 장비 수.

### 계속 미지원으로 남겨야 함

- 0~14성 현재 성공·유지 확률.
- 모든 구간의 기본 강화 메소 절대 비용.
- 일반 장비 흔적 복구의 기본 메소 산식 또는 절대 비용.
- 파괴 방지 시 유지 확률로의 정확한 재배분 수치.
- MVP, PC방, 썬데이 메이플 등 할인·이벤트를 반영한 실제 지불액. 이벤트별 기간과 조건이 달라 본 조사 범위에서 제외했다.
