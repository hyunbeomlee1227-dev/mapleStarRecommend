첫 작업은 공식 자료 조사다. API 문서 확인과 인증된 실제 응답 검증을 구분한다. 전 직업 계산과 목표 충족 판정은 검증되지 않은 수치를 공개하지 않는다. 기술 스택과 관리자 기준 편집 방식은 조사 후 결정한다.

## 2026-09-09 진행 상황

- [API 조사](api-research.md): 공식 스키마 필드, 운영 한도와 데이터 부족분 확인. 실응답은 아직 검증하지 않았다.
- [강화 규칙 조사](upgrade-rules-research.md): 공식 잠재 비용표와 보존 규칙, 스타포스 개편 근거 확인. 최신 전체 수치 검증은 08로 분리했다.
- 다음 작업은 02의 직업별 모델 조사와 03의 캐릭터 조회 기반이다. 01의 수치 미확인 항목은 08에서 이어가며, 미검증 수치를 추천에 사용하지 않는다.
